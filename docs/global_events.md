# Глобальні події будівництва

Глобальна подія збирає внески гравців для одного або кількох підприємств у відкритому секторі. Кожне підприємство має власні потреби й таймер. Загальний відсоток збору дорівнює середньому відсотків за типами необхідних ресурсів. На 10% змінюється зображення фундаменту. Після виконання кожної потреби починається будівництво. Каркас триває 72 години, зведення будівлі ще 48 годин. Підприємство автоматично починає працювати після 120 годин. Подія завершується після запуску останнього підприємства.

## Як підготувати першу подію

1. Відкрий **Адміністрування → Глобальні події** і вибери столицю.
2. Заповни назву, короткий і повний описи, правила, умови завершення та опис потенційних нагород. Вибери готове зображення зі списку або завантаж PNG, JPEG, WebP чи GIF до 8 МБ.
3. Додай одне або кілька підприємств. Укажи потрібну кількість кожного ресурсу, розміри складу й штат, зарплату, базову ціну продукції, площу та початковий баланс. Початкові запаси нового підприємства дорівнюють нулю.
4. Якщо в столиці є невикористана заготовка Штольні тихого пилу, Іскроломні чи Соляних копалень, постав позначку **Використати наявну порожню заготовку в столиці**. Сервер повторно перевірить запаси, баланс та історію операцій. Заготовку можна використати для однієї шахти. Шахти одного типу можна додавати окремо, зокрема якщо такий тип уже працює в секторі. Смолокурня і Кар’єр кісткового каменю залишаються у звичайному режимі. Лісопильня відсутня в каталозі будівництва.
   У переліку підприємств розкрий **Зображення п’яти стадій**. Для кожної стадії можна вибрати готову ілюстрацію або завантажити файл. Порожнє поле використовує стандартне зображення типу. Після запуску зображення також можна відредагувати окремо для кожної шахти в картці події. Щоб розрізняти шахти одного типу, можна задати власні назви.
5. В оцінці внесків золото коштує 1. Для інших ресурсів використовується базова ціна наявного підприємства або ціна продукції в налаштуваннях події. Якщо такої ціни немає, заповни відповідне поле вручну. Кожен внесок фіксує свою ціну та оціночну вартість.
6. Збережи чернетку, перевір повідомлення й натисни **Запустити подію**, підтвердивши дію. Будівництво з’явиться у вкладці **Шахти**, а сповіщення відкриється у модальному вікні. Незакрите повідомлення зберігається для гравця. Після закриття він може повернутися до події зі сторінки персонажа або рейтингу.
7. Після завершення відкрий **Нагороди події**. Вкажи коефіцієнт, фіксоване золото, ресурси й предмети для всіх, за місцем у рейтингу або для окремого гравця. Перевір розрахунок і підтвердь видачу. Дробове золото відкидається. Предмети копіюються з каталогу магазину без витрачання його запасу.
8. Перевір журнал видачі. Якщо операція не виконалась, усунь причину і натисни **Повторити невидані нагороди**. Підтверджений план зберігається. Видані нагороди залишаються у внутрішньому аудиті й не потрапляють у публічний протокол передач.

## Конфігурація й експлуатація

- Міграція `20261127_33` дозволяє шахти одного типу в одній події та зберігає окремий початковий баланс для кожної. Міграція Alembic `20261127_32` додає таблиці подій, будівництва, внесків, видачі й аудиту та розширює таблицю новин. Розгортання потребує `alembic upgrade head`. Міграція не створює й не запускає подій.
- `content/enterprise_construction.json` визначає каталог доступних типів, номер набору ілюстрацій, заготовки та доступність типів. Кількість шахт у секторі не обмежена. Необов’язковий список `sectors` обмежує конкретний тип. За відсутності списку шахту можна будувати у відкритому секторі з підтримкою підприємств.
- Ілюстрації стадій зберігаються у `frontend/static/images/enterprise_construction/stages/` і доступні за адресами `/static/images/enterprise_construction/stages/`. Завантажені вручну зображення зберігаються у `frontend/static/images/enterprise_construction/events/`. На хостингу з ефемерним диском використовуй готове зображення або зроби каталог завантажень постійним і спільним для всіх процесів.
- Внески, запуск і видача серіалізуються через той самий замок транзакції, що й редагування світу. Грошова оцінка внесків доступна тільки в статистиці адміністратора. Сторінка підприємства й мапа оновлюють прогрес кожні 5 секунд, сторінка статистики подій кожні 15 секунд. Фонова задача перевіряє готовність щохвилини та одразу після старту сервера. Запит до підприємства або події також матеріалізує вже минулі дедлайни.
- Скасування доступне до першого внеску. Автоматичне повернення ресурсів не передбачене. Повторне підтвердження того самого внеску використовує ідентифікатор операції. Після фіксації плану винагород зміни до виданих записів заборонені.
- Міграції слід застосувати до запуску нової версії застосунку. Після появи реальних внесків відкат схеми видаляє журнали подій, хоча уже нараховані цінності та побудовані підприємства зберігаються. Для повного відкату використовується резервна копія.

## API

| Метод | Маршрут | Призначення |
|---|---|---|
| GET | `/events`, `/events/active` | Історія подій і перелік активних подій |
| GET | `/events/{id}`, `/events/{id}/statistics`, `/events/{id}/contributions/me` | Сторінка, рейтинг з фільтрами і власний внесок |
| GET | `/enterprise/{id}/construction` | Стан будівництва для гравця в секторі |
| POST | `/enterprise/{id}/construction/contribute` | Атомарний внесок із UUID операції |
| GET | `/admin/events`, `/admin/events/{id}` | Панель подій і картка події |
| POST / PATCH | `/admin/events`, `/admin/events/{id}` | Створення або редагування чернетки |
| POST | `/admin/events/image` | Завантаження зображення |
| PATCH | `/admin/events/{id}/enterprises/{enterprise_id}/images` | Зображення стадій конкретної шахти |
| POST | `/admin/events/{id}/start`, `/admin/events/{id}/cancel` | Запуск і скасування з підтвердженням |
| GET | `/admin/events/{id}/statistics`, `/admin/events/{id}/rewards` | Внески й внутрішній журнал винагород |
| POST | `/admin/events/{id}/rewards/preview`, `/admin/events/{id}/rewards/issue` | Попередній розрахунок, підтвердження та повтор видачі |

Сповіщення використовують наявні `GET /api/news/latest` і `POST /api/news/{id}/acknowledge`.
